# macctrl 实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在 X11 下把所有键盘的 Mac Command 组合按焦点窗口类型（终端 / 普通 GUI）转换为 Ctrl 组合，且每条快捷键可单独开关。

**Architecture:** 单进程 Rust 守护进程。每个键盘一个读取线程，`EVIOCGRAB` 独占后经延迟修饰键状态机决定"吞掉并注入"还是"原样转发"，统一由单个 uinput 虚拟键盘输出；焦点类型通过 x11rb 查询 `_NET_ACTIVE_WINDOW`/`WM_CLASS` 判定。纯逻辑（键解析、绑定目录、配置合并、状态机、设备筛选）全部无 IO，用单元测试覆盖。

**Tech Stack:** Rust 2021、evdev 0.13（含 uinput）、x11rb 0.13、clap 4、serde + toml 0.8、anyhow、log + env_logger。

**依据 spec:** [2026-11-27-macctrl-design.md](../specs/2026-11-27-macctrl-design.md)

- [ ] **Step 3: 实现 key.rs**

> 实现提示：Linux 字母键码**不按字母顺序递增**（A=30、S=31、Z=44…）。`parse_key` / `key_name` 必须用显式的 26 项映射表，不能用 `KEY_A + offset` 算术。

```rust
use anyhow::{bail, Result};
use evdev::KeyCode;

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub struct KeyPattern {
    pub shift: bool,
    pub code: KeyCode,
}

impl KeyPattern {
    /// 解析 "z" / "shift+z"；仅允许可选的 shift 前缀。
    pub fn parse(s: &str) -> Result<Self> {
        let s = s.trim();
        let (shift, name) = match s.strip_prefix("shift+") {
            Some(rest) => (true, rest.trim()),
            None => (false, s),
        };
        if name.contains('+') {
            bail!("不支持的修饰键组合: {s}（只允许可选 shift 前缀）");
        }
        let code = parse_key(name).ok_or_else(|| anyhow::anyhow!("未知按键名: {name}"))?;
        Ok(Self { shift, code })
    }

    pub fn label(&self) -> String {
        let base = key_name(self.code).unwrap_or_else(|| self.code.0.to_string());
        if self.shift {
            format!("super+shift+{base}")
        } else {
            format!("super+{base}")
        }
    }
}

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum Modifier {
    Ctrl,
    Shift,
    Alt,
}

#[derive(Debug, Clone, PartialEq, Eq)]
pub struct Chord {
    pub mods: Vec<Modifier>,
    pub code: KeyCode,
}

impl Chord {
    /// 解析 "ctrl+c" / "ctrl+shift+c" / "home"。
    pub fn parse(s: &str) -> Result<Self> {
        let parts: Vec<&str> = s.split('+').map(str::trim).filter(|p| !p.is_empty()).collect();
        if parts.is_empty() {
            bail!("空的按键序列");
        }
        let (key, mods_str) = parts.split_last().unwrap();
        let mut mods = Vec::new();
        for m in mods_str {
            let md = match *m {
                "ctrl" => Modifier::Ctrl,
                "shift" => Modifier::Shift,
                "alt" => Modifier::Alt,
                other => bail!("未知修饰键: {other}"),
            };
            if !mods.contains(&md) {
                mods.push(md);
            }
        }
        let code = parse_key(key).ok_or_else(|| anyhow::anyhow!("未知按键名: {key}"))?;
        Ok(Self { mods, code })
    }

    pub fn label(&self) -> String {
        let mut out = String::new();
        for m in &self.mods {
            out.push_str(match m {
                Modifier::Ctrl => "ctrl+",
                Modifier::Shift => "shift+",
                Modifier::Alt => "alt+",
            });
        }
        out.push_str(&key_name(self.code).unwrap_or_else(|| self.code.0.to_string()));
        out
    }

    fn mod_code(m: Modifier) -> u16 {
        match m {
            Modifier::Ctrl => KeyCode::KEY_LEFTCTRL.0,
            Modifier::Shift => KeyCode::KEY_LEFTSHIFT.0,
            Modifier::Alt => KeyCode::KEY_LEFTALT.0,
        }
    }

    /// 生成注入序列：(keycode, value)。
    /// skip_shift 为 true 时跳过 Shift 的按下/释放（物理 Shift 已转发且仍按住）。
    pub fn events(&self, skip_shift: bool) -> Vec<(u16, i32)> {
        let mut out = Vec::new();
        for m in &self.mods {
            if skip_shift && *m == Modifier::Shift {
                continue;
            }
            out.push((Self::mod_code(*m), 1));
        }
        out.push((self.code.0, 1));
        out.push((self.code.0, 0));
        for m in self.mods.iter().rev() {
            if skip_shift && *m == Modifier::Shift {
                continue;
            }
            out.push((Self::mod_code(*m), 0));
        }
        out
    }
}

pub fn parse_key(name: &str) -> Option<KeyCode> {
    let lower = name.trim().to_ascii_lowercase();
    let n = lower.as_str();
    if n.len() == 1 {
        let b = n.as_bytes()[0];
        if b.is_ascii_lowercase() {
            return Some(KeyCode::new(KeyCode::KEY_A.0 + (b - b'a') as u16));
        }
        if (b'1'..=b'9').contains(&b) {
            return Some(KeyCode::new(KeyCode::KEY_1.0 + (b - b'1') as u16));
        }
        if b == b'0' {
            return Some(KeyCode::KEY_0);
        }
    }
    Some(match n {
        "comma" => KeyCode::KEY_COMMA,
        "dot" => KeyCode::KEY_DOT,
        "slash" => KeyCode::KEY_SLASH,
        "semicolon" => KeyCode::KEY_SEMICOLON,
        "apostrophe" => KeyCode::KEY_APOSTROPHE,
        "grave" => KeyCode::KEY_GRAVE,
        "leftbrace" => KeyCode::KEY_LEFTBRACE,
        "rightbrace" => KeyCode::KEY_RIGHTBRACE,
        "backslash" => KeyCode::KEY_BACKSLASH,
        "equal" => KeyCode::KEY_EQUAL,
        "minus" => KeyCode::KEY_MINUS,
        "enter" => KeyCode::KEY_ENTER,
        "tab" => KeyCode::KEY_TAB,
        "space" => KeyCode::KEY_SPACE,
        "backspace" => KeyCode::KEY_BACKSPACE,
        "delete" => KeyCode::KEY_DELETE,
        "insert" => KeyCode::KEY_INSERT,
        "escape" => KeyCode::KEY_ESC,
        "home" => KeyCode::KEY_HOME,
        "end" => KeyCode::KEY_END,
        "pageup" => KeyCode::KEY_PAGEUP,
        "pagedown" => KeyCode::KEY_PAGEDOWN,
        "left" => KeyCode::KEY_LEFT,
        "right" => KeyCode::KEY_RIGHT,
        "up" => KeyCode::KEY_UP,
        "down" => KeyCode::KEY_DOWN,
        _ => return None,
    })
}

pub fn key_name(code: KeyCode) -> Option<String> {
    if (KeyCode::KEY_A.0..=KeyCode::KEY_Z.0).contains(&code.0) {
        return Some(((b'a' + (code.0 - KeyCode::KEY_A.0) as u8) as char).to_string());
    }
    if (KeyCode::KEY_1.0..=KeyCode::KEY_9.0).contains(&code.0) {
        return Some(((b'1' + (code.0 - KeyCode::KEY_1.0) as u8) as char).to_string());
    }
    let name = match code {
        KeyCode::KEY_0 => "0",
        KeyCode::KEY_COMMA => "comma",
        KeyCode::KEY_DOT => "dot",
        KeyCode::KEY_SLASH => "slash",
        KeyCode::KEY_SEMICOLON => "semicolon",
        KeyCode::KEY_APOSTROPHE => "apostrophe",
        KeyCode::KEY_GRAVE => "grave",
        KeyCode::KEY_LEFTBRACE => "leftbrace",
        KeyCode::KEY_RIGHTBRACE => "rightbrace",
        KeyCode::KEY_BACKSLASH => "backslash",
        KeyCode::KEY_EQUAL => "equal",
        KeyCode::KEY_MINUS => "minus",
        KeyCode::KEY_ENTER => "enter",
        KeyCode::KEY_TAB => "tab",
        KeyCode::KEY_SPACE => "space",
        KeyCode::KEY_BACKSPACE => "backspace",
        KeyCode::KEY_DELETE => "delete",
        KeyCode::KEY_INSERT => "insert",
        KeyCode::KEY_ESC => "escape",
        KeyCode::KEY_HOME => "home",
        KeyCode::KEY_END => "end",
        KeyCode::KEY_PAGEUP => "pageup",
        KeyCode::KEY_PAGEDOWN => "pagedown",
        KeyCode::KEY_LEFT => "left",
        KeyCode::KEY_RIGHT => "right",
        KeyCode::KEY_UP => "up",
        KeyCode::KEY_DOWN => "down",
        _ => return None,
    };
    Some(name.to_string())
}
```

```rust
pub struct BindingTable {
    bindings: Vec<Binding>,
}

impl BindingTable {
    pub fn new(bindings: Vec<Binding>) -> Result<Self> {
        let mut seen: HashMap<(bool, u16), String> = HashMap::new();
        for b in &bindings {
            if !b.enabled {
                continue;
            }
            let key = (b.pattern.shift, b.pattern.code.0);
            if let Some(prev) = seen.insert(key, b.id.clone()) {
                bail!(
                    "按键模式 {} 被多个已启用绑定使用: {prev} / {}",
                    b.pattern.label(),
                    b.id
                );
            }
        }
        Ok(Self { bindings })
    }

    pub fn resolve(&self, pattern: KeyPattern, mode: Mode) -> Option<(String, Chord)> {
        let b = self.bindings.iter().find(|b| b.pattern == pattern && b.enabled)?;
        let chord = b.target(mode)?.clone();
        Some((b.id.clone(), chord))
    }

    pub fn set_enabled(&mut self, id: &str, enabled: bool) -> Result<()> {
        let b = self
            .bindings
            .iter_mut()
            .find(|b| b.id == id)
            .ok_or_else(|| anyhow::anyhow!("未知绑定 id: {id}"))?;
        b.enabled = enabled;
        Ok(())
    }

    pub fn all(&self) -> &[Binding] {
        &self.bindings
    }

    pub fn all_injected_keys(&self) -> Vec<evdev::KeyCode> {
        let mut keys = Vec::new();
        for b in &self.bindings {
            for chord in [b.gui.as_ref(), b.terminal.as_ref()].into_iter().flatten() {
                keys.push(chord.code);
                for m in &chord.mods {
                    keys.push(match m {
                        crate::key::Modifier::Ctrl => evdev::KeyCode::KEY_LEFTCTRL,
                        crate::key::Modifier::Shift => evdev::KeyCode::KEY_LEFTSHIFT,
                        crate::key::Modifier::Alt => evdev::KeyCode::KEY_LEFTALT,
                    });
                }
            }
        }
        keys.sort_by_key(|k| k.0);
        keys.dedup();
        keys
    }
}

    .unwrap();

use std::collections::BTreeMap;
use std::path::Path;

use anyhow::{bail, Context, Result};
use serde::Deserialize;

use crate::binding::{Binding, Source};
use crate::key::{Chord, KeyPattern};

pub const DEFAULT_TERMINAL_CLASSES: &[&str] = &[
    "deepin-terminal", "gnome-terminal", "kgx", "konsole", "xfce4-terminal",
    "xterm", "urxvt", "alacritty", "kitty", "wezterm", "tilix",
    "terminator", "st", "mate-terminal", "lxterminal", "qterminal", "sakura",
];

#[derive(Debug, Default, Deserialize)]
pub struct Config {
    #[serde(default)]
    pub device: DeviceConfig,
    #[serde(default)]
    pub x11: X11Config,
    #[serde(default)]
    pub bindings: BTreeMap<String, BindingOverride>,
}

#[derive(Debug, Default, Deserialize)]
pub struct DeviceConfig {
    #[serde(default)]
    pub include_patterns: Vec<String>,
    #[serde(default)]
    pub exclude_patterns: Vec<String>,
}

#[derive(Debug, Default, Deserialize)]
pub struct X11Config {
    #[serde(default)]
    pub terminal_classes: Vec<String>,
}

#[derive(Debug, Default, Deserialize)]
pub struct BindingOverride {
    pub enabled: Option<bool>,
    pub gui: Option<String>,
    pub terminal: Option<String>,
    pub keys: Option<String>,
}

impl Config {
    pub fn load(path: Option<&Path>) -> Result<Self> {
        let Some(path) = path else {
            let default = default_path();
            if default.exists() {
                return Self::load_file(&default);
            }
            return Ok(Self::default());
        };
        Self::load_file(path)
    }

    fn load_file(path: &Path) -> Result<Self> {
        let text = std::fs::read_to_string(path)
            .with_context(|| format!("读取配置失败: {}", path.display()))?;
        Self::parse(&text).with_context(|| format!("解析配置失败: {}", path.display()))
    }

    pub fn parse(text: &str) -> Result<Self> {
        if text.trim().is_empty() {
            return Ok(Self::default());
        }
        Ok(toml::from_str(text)?)
    }

    pub fn terminal_classes(&self) -> Vec<String> {
        if self.x11.terminal_classes.is_empty() {
            DEFAULT_TERMINAL_CLASSES.iter().map(|s| s.to_string()).collect()
        } else {
            self.x11.terminal_classes.iter().map(|s| s.to_ascii_lowercase()).collect()
        }
    }

    pub fn apply(&self, builtin: Vec<Binding>) -> Result<Vec<Binding>> {
        let mut list = builtin;
        for (id, ov) in &self.bindings {
            let idx = list.iter().position(|b| &b.id == id);
            match idx {
                Some(i) => {
                    if ov.keys.is_some() {
                        bail!("内置绑定 {id} 不支持覆盖 keys（如需新组合请使用新的 id）");
                    }
                    let b = &mut list[i];
                    if let Some(enabled) = ov.enabled {
                        b.enabled = enabled;
                    }
                    if let Some(gui) = &ov.gui {
                        b.gui = if gui.is_empty() {
                            None
                        } else {
                            Some(Chord::parse(gui).with_context(|| format!("绑定 {id} 的 gui 非法"))?)
                        };
                    }
                    if let Some(terminal) = &ov.terminal {
                        b.terminal = if terminal.is_empty() {
                            None
                        } else {
                            Some(
                                Chord::parse(terminal)
                                    .with_context(|| format!("绑定 {id} 的 terminal 非法"))?,
                            )
                        };
                    }
                    b.source = Source::Config;
                }
                None => {
                    let keys = ov
                        .keys
                        .as_ref()
                        .ok_or_else(|| anyhow::anyhow!("自定义绑定 {id} 缺少 keys"))?;
                    let gui = ov
                        .gui
                        .as_ref()
                        .ok_or_else(|| anyhow::anyhow!("自定义绑定 {id} 缺少 gui"))?;
                    let pattern = KeyPattern::parse(keys)
                        .with_context(|| format!("绑定 {id} 的 keys 非法"))?;
                    let gui = Chord::parse(gui).with_context(|| format!("绑定 {id} 的 gui 非法"))?;
                    let terminal = match &ov.terminal {
                        Some(s) if s.is_empty() => None,
                        Some(s) => Some(
                            Chord::parse(s).with_context(|| format!("绑定 {id} 的 terminal 非法"))?,
                        ),
                        None => None,
                    };
                    list.push(Binding {
                        id: id.clone(),
                        pattern,
                        gui: Some(gui),
                        terminal,
                        enabled: ov.enabled.unwrap_or(true),
                        source: Source::Config,
                    });
                }
            }
        }
        Ok(list)
    }

    pub fn apply_cli(&self, list: &mut [Binding], enable: &[String], disable: &[String]) -> Result<()> {
        for id in enable {
            let b = list
                .iter_mut()
                .find(|b| &b.id == id)
                .ok_or_else(|| anyhow::anyhow!("未知绑定 id: {id}"))?;
            b.enabled = true;
            b.source = Source::Cli;
        }
        for id in disable {
            let b = list
                .iter_mut()
                .find(|b| &b.id == id)
                .ok_or_else(|| anyhow::anyhow!("未知绑定 id: {id}"))?;
            b.enabled = false;
            b.source = Source::Cli;
        }
        Ok(())
    }
}

pub fn default_path() -> std::path::PathBuf {
    let base = std::env::var_os("XDG_CONFIG_HOME")
        .map(std::path::PathBuf::from)
        .unwrap_or_else(|| {
            std::path::PathBuf::from(std::env::var_os("HOME").unwrap_or_default()).join(".config")
        });
    base.join("macctrl").join("config.toml")
}

    Inject { id: String, chord: Chord, skip_shift: bool },
}

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
enum State {
    Idle,
    Pending,
    Forwarded,
    Consumed(u16),
}

pub struct Machine {
    state: State,
    shift_buffered: bool,
    shift_forwarded: bool,
}

const SUPER_L: u16 = KeyCode::KEY_LEFTMETA.0;
const SUPER_R: u16 = KeyCode::KEY_RIGHTMETA.0;
const SHIFT_L: u16 = KeyCode::KEY_LEFTSHIFT.0;
const SHIFT_R: u16 = KeyCode::KEY_RIGHTSHIFT.0;
const CTRL_L: u16 = KeyCode::KEY_LEFTCTRL.0;
const CTRL_R: u16 = KeyCode::KEY_RIGHTCTRL.0;
const ALT_L: u16 = KeyCode::KEY_LEFTALT.0;
const ALT_R: u16 = KeyCode::KEY_RIGHTALT.0;

fn ev_key(code: u16, value: i32) -> Ev {
    Ev::Key { code, value }
}

impl Default for Machine {
    fn default() -> Self {
        Self::new()
    }
}

impl Machine {
    pub fn new() -> Self {
        Self { state: State::Idle, shift_buffered: false, shift_forwarded: false }
    }

    pub fn step<F: FnOnce() -> Mode>(&mut self, ev: Ev, table: &BindingTable, mode: F) -> Vec<Out> {
        let (code, value) = match ev {
            Ev::Key { code, value } => (code, value),
            Ev::Raw { .. } => return vec![Out::Pass(ev)],
        };

        if code == SUPER_L || code == SUPER_R {
            return self.on_super(value, ev);
        }
        if code == SHIFT_L || code == SHIFT_R {
            return self.on_shift(value, ev);
        }
        if code == CTRL_L || code == CTRL_R || code == ALT_L || code == ALT_R {
            return self.on_ctrl_alt(value, ev);
        }

        match self.state {
            State::Pending => {
                if value == 1 {
                    let pattern = KeyPattern {
                        shift: self.shift_buffered || self.shift_forwarded,
                        code: KeyCode::new(code),
                    };
                    if let Some((id, chord)) = table.resolve(pattern, mode()) {
                        let skip_shift = self.shift_forwarded;
                        self.state = State::Consumed(code);
                        return vec![Out::Inject { id, chord, skip_shift }];
                    }
                }
                self.flush_pending(code, value)
            }
            State::Consumed(_) => vec![Out::Pass(ev)],
            _ => vec![Out::Pass(ev)],
        }
    }

    fn flush_pending(&mut self, code: u16, value: i32) -> Vec<Out> {
        let mut out = vec![Out::Pass(ev_key(SUPER_L, 1))];
        if self.shift_buffered {
            out.push(Out::Pass(ev_key(SHIFT_L, 1)));
            self.shift_forwarded = true;
            self.shift_buffered = false;
        }
        out.push(Out::Pass(ev_key(code, value)));
        self.state = State::Forwarded;
        out
    }

    fn on_super(&mut self, value: i32, ev: Ev) -> Vec<Out> {
        match (self.state, value) {
            (State::Idle, 1) => {
                self.state = State::Pending;
                vec![]
            }
            (State::Pending, 1) | (State::Pending, 2) => vec![],
            (State::Pending, 0) => {
                let mut out = Vec::new();
                if self.shift_buffered {
                    out.push(Out::Pass(ev_key(SHIFT_L, 1)));
                }
                out.push(Out::Pass(ev_key(SUPER_L, 1)));
                out.push(Out::Pass(ev_key(SUPER_L, 0)));
                if self.shift_buffered {
                    self.shift_buffered = false;
                    self.shift_forwarded = true;
                }
                self.state = State::Idle;
                out
            }
            (State::Consumed(_), 0) => {
                self.state = State::Idle;
                vec![]
            }
            (_, 0) => {
                self.state = State::Idle;
                vec![Out::Pass(ev)]
            }
            _ => vec![Out::Pass(ev)],
        }
    }

    fn on_shift(&mut self, value: i32, ev: Ev) -> Vec<Out> {
        match (self.state, value) {
            (State::Pending, 1) => {
                self.shift_buffered = true;
                vec![]
            }
            (State::Pending, 2) => vec![],
            (State::Pending, 0) => {
                let mut out = vec![Out::Pass(ev_key(SUPER_L, 1))];
                if self.shift_buffered {
                    out.push(Out::Pass(ev_key(SHIFT_L, 1)));
                    out.push(Out::Pass(ev_key(SHIFT_L, 0)));
                    self.shift_buffered = false;
                    self.shift_forwarded = false;
                } else {
                    out.push(Out::Pass(ev));
                    self.shift_forwarded = false;
                }
                self.state = State::Forwarded;
                out
            }
            (State::Consumed(_), 0) => {
                if self.shift_buffered {
                    self.shift_buffered = false;
                    vec![]
                } else {
                    self.shift_forwarded = false;
                    vec![Out::Pass(ev)]
                }
            }
            (_, 0) => {
                self.shift_forwarded = false;
                vec![Out::Pass(ev)]
            }
            (_, 1) => {
                self.shift_forwarded = true;
                vec![Out::Pass(ev)]
            }
            _ => vec![],
        }
    }

    fn on_ctrl_alt(&mut self, value: i32, ev: Ev) -> Vec<Out> {
        if value == 1 && self.state == State::Pending {
            let mut out = vec![Out::Pass(ev_key(SUPER_L, 1))];
            if self.shift_buffered {
                out.push(Out::Pass(ev_key(SHIFT_L, 1)));
                self.shift_forwarded = true;
                self.shift_buffered = false;
            }
            out.push(Out::Pass(ev));
            self.state = State::Forwarded;
            return out;
        }
        vec![Out::Pass(ev)]
    }
}

/// 键盘能力判定：必须具备字母、空格与回车，排除电源键、纯媒体键等设备。
pub fn is_keyboard(keys: &AttributeSetRef<KeyCode>) -> bool {

        && keys.contains(KeyCode::KEY_SPACE)

/// include 为空表示全部；exclude 优先于 include；不区分大小写，子串匹配。
pub fn matches_filters(name: &str, include: &[String], exclude: &[String]) -> bool {
    let n = name.to_ascii_lowercase();
    if exclude.iter().any(|p| n.contains(&p.to_ascii_lowercase())) {
        return false;
    }
    include.is_empty() || include.iter().any(|p| n.contains(&p.to_ascii_lowercase()))
}

use anyhow::{Context, Result};
use x11rb::protocol::xproto::{AtomEnum, ConnectionExt, Window};

use crate::binding::Mode;

/// 从 WM_CLASS 原始字节解析 (instance, class)。
pub fn parse_wm_class(raw: &[u8]) -> Option<(String, String)> {
    let mut it = raw.split(|b| *b == 0).filter(|part| !part.is_empty());
    let instance = String::from_utf8_lossy(it.next()?).to_string();
    let class = it.next().map(|c| String::from_utf8_lossy(c).to_string()).unwrap_or_else(|| instance.clone());
    Some((instance, class))
}

pub fn is_terminal_class(instance: &str, class: &str, whitelist: &[String]) -> bool {
    let i = instance.to_ascii_lowercase();
    let c = class.to_ascii_lowercase();
    whitelist.iter().any(|w| *w == i || *w == c)
}

pub struct FocusProbe {
    conn: x11rb::rust_connection::RustConnection,
    root: Window,
    active_atom: u32,
}

impl FocusProbe {
    pub fn connect() -> Result<Self> {
        let (conn, screen) = x11rb::connect(None).context("连接 X11 失败")?;
        let root = conn.setup().roots[screen].root;
        let active_atom = conn
            .intern_atom(false, b"_NET_ACTIVE_WINDOW")?
            .reply()?
            .atom;
        Ok(Self { conn, root, active_atom })
    }

    /// 任何查询异常都回退到终端模式：误发 Ctrl+Shift+C 无害，误发 Ctrl+C 会杀进程。
    pub fn mode(&self, classes: &[String]) -> Mode {
        match self.active_window() {
            Ok(Some(win)) => match self.wm_class(win) {
                Ok(Some((instance, class))) => {
                    if is_terminal_class(&instance, &class, classes) {
                        Mode::Terminal
                    } else {
                        Mode::Gui
                    }
                }
                Ok(None) => Mode::Gui,
                Err(_) => Mode::Terminal,
            },
            Ok(None) => Mode::Gui,
            Err(_) => Mode::Terminal,
        }
    }

    fn active_window(&self) -> Result<Option<Window>> {
        let reply = self
            .conn
            .get_property(false, self.root, AtomEnum::WINDOW, self.active_atom, 0, 1)?
            .reply()?;
        Ok(reply.value32().and_then(|mut it| it.next()))
    }

    fn wm_class(&self, win: Window) -> Result<Option<(String, String)>> {
        let mut cur = win;
        for _ in 0..16 {
            let reply = self
                .conn
                .get_property(false, cur, AtomEnum::WM_CLASS, AtomEnum::STRING, 0, 1024)?
                .reply()?;
            if let Some(pair) = parse_wm_class(&reply.value) {
                return Ok(Some(pair));
            }
            let tree = self.conn.query_tree(cur)?.reply()?;
            if tree.parent == 0 || tree.parent == self.root {
                break;
            }
            cur = tree.parent;
        }
        Ok(None)
    }
}

use anyhow::{Context, Result};
use evdev::uinput::VirtualDevice;
use evdev::{AttributeSet, EventType, InputEvent, KeyCode};

use crate::state::{Ev, Out};

pub enum Sink {
    Real(VirtualDevice),
    Dry,
}

impl Sink {
    pub fn real(keys: &AttributeSet<KeyCode>) -> Result<Self> {
        let dev = VirtualDevice::builder()?
            .name("macctrl virtual keyboard")
            .with_keys(keys)?
            .build()
            .context("创建 uinput 设备失败（检查 /dev/uinput 权限与 input 组）")?;
        Ok(Self::Real(dev))
    }

    pub fn dry() -> Self {
        Self::Dry
    }

    pub fn emit(&mut self, out: &Out) -> Result<()> {
        if let Sink::Dry = self {
            if let Out::Inject { id, chord, skip_shift } = out {
                println!("[dry-run] 命中 {id} -> {} (skip_shift={skip_shift})", chord.label());
            }
            return Ok(());
        }
        let events = events_for(out);
        if events.is_empty() {
            return Ok(());
        }
        let batch: Vec<InputEvent> = events
            .iter()
            .map(|(t, c, v)| InputEvent::new(*t, *c, *v))
            .collect();
        if let Sink::Real(dev) = self {
            dev.emit(&batch)?;
        }
        Ok(())
    }
}

/// 把状态机输出展开为 (type, code, value) 序列；uinput 的 emit 会自动补 SYN_REPORT。
pub fn events_for(out: &Out) -> Vec<(u16, u16, i32)> {
    match out {
        Out::Pass(Ev::Key { code, value }) => vec![(EventType::KEY.0, *code, *value)],
        Out::Pass(Ev::Raw { type_, code, value }) => vec![(*type_, *code, *value)],
        Out::Inject { chord, skip_shift, .. } => chord
            .events(*skip_shift)
            .into_iter()
            .map(|(c, v)| (EventType::KEY.0, c, v))
            .collect(),
    }
}

    let keyboards = collect_keyboards(&include, &exclude);
    if keyboards.is_empty() {
        warn!("未发现可用键盘，等待热插拔（每 2 秒重扫）");
    }

    let sink = if dry_run {
        info!("dry-run 模式：被动读取设备，不抓取、不注入");
        Arc::new(Mutex::new(Sink::dry()))
    } else {
        let mut keys = AttributeSet::<KeyCode>::new();
        for (_, dev) in &keyboards {
            if let Some(supported) = dev.supported_keys() {
                for k in supported.iter() {
                    keys.insert(k);
                }
            }
        }
        for k in table.all_injected_keys() {
            keys.insert(k);
        }
        Arc::new(Mutex::new(Sink::real(&keys)?))
    };

    let mut running: HashMap<PathBuf, thread::JoinHandle<()>> = HashMap::new();
    for (path, dev) in keyboards {
        spawn_device(path, dev, table.clone(), classes.clone(), sink.clone(), !dry_run, &mut running);
    }

    loop {
        thread::sleep(Duration::from_secs(2));
        running.retain(|_, h| !h.is_finished());
        for (path, dev) in collect_keyboards(&include, &exclude) {
            if !running.contains_key(&path) {
                spawn_device(path, dev, table.clone(), classes.clone(), sink.clone(), !dry_run, &mut running);
            }
        }
    }
}

fn collect_keyboards(include: &[String], exclude: &[String]) -> Vec<(PathBuf, Device)> {
    evdev::enumerate()
        .filter(|(_, dev)| {
            dev.name()
                .map(|n| device::matches_filters(n, include, exclude) && !n.contains("macctrl"))
                .unwrap_or(false)
        })
        .filter(|(_, dev)| dev.supported_keys().map(device::is_keyboard).unwrap_or(false))
        .collect()
}

fn spawn_device(
    path: PathBuf,
    mut dev: Device,
    table: Arc<BindingTable>,
    classes: Arc<Vec<String>>,
    sink: Arc<Mutex<Sink>>,
    grab: bool,
    running: &mut HashMap<PathBuf, thread::JoinHandle<()>>,
) {
    let name = dev.name().unwrap_or("<unknown>").to_string();
    let shown_path = path.display().to_string();
    let handle = thread::spawn(move || {
        if grab {
            if let Err(e) = dev.grab() {
                warn!("抓取 {name} ({shown_path}) 失败: {e}");
                return;
            }
            info!("已接管键盘: {name} ({shown_path})");
        }
        let mut machine = Machine::new();
        let probe = FocusProbe::connect().ok();
        loop {
            let stream = match dev.fetch_events() {
                Ok(s) => s,
                Err(e) => {
                    warn!("读取 {name} 失败，释放该设备: {e}");
                    return;
                }
            };
            for raw in stream {
                // 只转发 EV_KEY：uinput.emit 会自动补 SYN_REPORT，EV_MSC 无转发价值。
                if raw.event_type() != EventType::KEY {
                    continue;
                }
                let ev = Ev::Key { code: raw.code(), value: raw.value() };
                let outs = machine.step(ev, &table, || {
                    probe.as_ref().map(|p| p.mode(&classes)).unwrap_or(Mode::Terminal)
                });
                let mut s = match sink.lock() {
                    Ok(s) => s,
                    Err(_) => return,
                };
                for out in &outs {
                    if let Err(e) = s.emit(out) {
                        warn!("注入失败，退出以恢复键盘: {e}");
                        return;
                    }
                }
            }
        }
    });
    running.insert(path, handle);
}
```

/// 把 Mac Command 组合映射为 Ctrl 组合（X11，终端感知）。
#[derive(Debug, Parser)]
#[command(version, about)]
pub struct Args {
    /// 配置文件路径（默认 ~/.config/macctrl/config.toml）
    #[arg(long)]
    pub config: Option<PathBuf>,
    /// 只处理名称匹配的键盘（可重复；默认处理所有键盘）
    #[arg(long = "device")]
    pub devices: Vec<String>,
    /// 列出事件设备
    #[arg(long)]
    pub list_devices: bool,
    /// 列出快捷键目录与启用状态
    #[arg(long)]
    pub list_bindings: bool,
    /// 本次运行强制启用某个绑定 id（可重复）
    #[arg(long = "enable")]
    pub enable: Vec<String>,
    /// 本次运行强制关闭某个绑定 id（可重复）
    #[arg(long = "disable")]
    pub disable: Vec<String>,
    /// 只观察并打印决策，不创建 uinput、不抓取键盘
    #[arg(long)]
    pub dry_run: bool,
    /// 输出调试日志
    #[arg(long)]
    pub verbose: bool,
}

fn main() -> Result<()> {
    let args = Args::parse();
    env_logger::Builder::from_env(
        env_logger::Env::default()
            .default_filter_or(if args.verbose { "debug" } else { "info" }),
    )
    .init();

    let session = std::env::var("XDG_SESSION_TYPE").unwrap_or_else(|_| "x11".to_string());
    if session != "x11" {
        bail!("仅支持 X11 会话，当前 XDG_SESSION_TYPE={session}");
    }

    let mut cfg = Config::load(args.config.as_deref())?;
    if !args.devices.is_empty() {
        cfg.device.include_patterns = args.devices.clone();
    }
    let mut bindings = cfg.apply(builtin_bindings())?;
    cfg.apply_cli(&mut bindings, &args.enable, &args.disable)?;
    let table = BindingTable::new(bindings)?;

    if args.list_bindings {
        print!("{}", list_bindings_text(table.all()));
        return Ok(());
    }

    if args.list_devices {
        for (path, dev) in evdev::enumerate() {
            let name = dev.name().unwrap_or("<unknown>");
            let keys = dev.supported_keys();
            let is_kb = keys.map(device::is_keyboard).unwrap_or(false);
            let selected = device::matches_filters(
                name,
                &cfg.device.include_patterns,
                &cfg.device.exclude_patterns,
            );
            println!(
                "{:<28} {:<40} keyboard={:<5} selected={}",
                path.display(),
                name,
                is_kb,
                is_kb && selected && !name.contains("macctrl")
            );
        }
        return Ok(());
    }

    runner::run_loop(table, cfg, args.dry_run)
}
